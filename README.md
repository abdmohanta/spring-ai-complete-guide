# 📖 Module 1 - Artificial Intelligence Fundamentals

Before learning Spring AI, it is important to understand the technologies that power it.

Spring AI is **not an AI model**. It is a framework that helps Java developers integrate AI models into Spring Boot applications.

Let's understand the complete AI ecosystem.

---

# 🧠 What is Artificial Intelligence (AI)?

Artificial Intelligence (AI) is the ability of a computer system to simulate human intelligence.

AI enables machines to perform tasks that normally require human intelligence such as:

- Understanding language
- Solving problems
- Making decisions
- Recognizing images
- Answering questions
- Learning from data

### Real World Examples

- ChatGPT
- Siri
- Google Assistant
- Alexa
- Netflix Recommendation
- Amazon Recommendation
- Self Driving Cars

---

# AI Evolution

```

Artificial Intelligence

↓

Machine Learning

↓

Deep Learning

↓

Generative AI

↓

Large Language Models

↓

Spring AI

```

---

# 🤖 What is Machine Learning?

Machine Learning (ML) is a subset of Artificial Intelligence.

Instead of writing rules manually, we provide data to the computer and allow it to learn patterns.

Traditional Programming

```

Input + Rules

↓

Program

↓

Output

```

Machine Learning

```

Input + Output

↓

Machine Learning Model

↓

Rules Learned Automatically

```

### Example

Spam Email Detection

Instead of writing

```

if(subject contains "Lottery")

Spam

```

We train the model using thousands of spam emails.

---

# 🧠 What is Deep Learning?

Deep Learning is a subset of Machine Learning.

It uses Neural Networks having many hidden layers.

Deep Learning powers

- ChatGPT
- Gemini
- Claude
- Image Generation
- Voice Recognition
- Self Driving Cars

---

# What is a Neural Network?

A Neural Network is inspired by the human brain.

```

Input Layer

↓

Hidden Layer

↓

Hidden Layer

↓

Output Layer

```

Each layer learns different patterns.

---

# What is Generative AI?

Generative AI creates new content instead of only analyzing existing data.

It can generate

- Text
- Images
- Videos
- Audio
- Source Code
- SQL Queries
- Emails

Examples

- ChatGPT
- Gemini
- Claude
- MidJourney
- DALL-E

# What is an LLM?

LLM stands for

## Large Language Model

It is a Deep Learning model trained on massive amounts of text data.

LLMs can

- Answer Questions
- Write Code
- Translate Languages
- Summarize Documents
- Explain Concepts
- Generate Images (through image models)
- Create Emails

Popular LLMs

| Company | Model |
|----------|----------------|
| OpenAI | GPT |
| Google | Gemini |
| Anthropic | Claude |
| Meta | Llama |
| DeepSeek | DeepSeek |
| Mistral | Mistral |
| Alibaba | Qwen |

---

# How does an LLM work?

```

User Prompt

↓

Tokenizer

↓

Tokens

↓

Large Language Model

↓

Prediction Engine

↓

Generated Response

```

The model predicts one token at a time.

---

# What is a Token?

A token is the smallest unit processed by an LLM.

Example

Sentence

```

Spring AI is amazing

```

Possible Tokens

```

Spring

AI

is

amazing

```

The model predicts the next token repeatedly.

---

# Token Example

Prompt

```

Java is

```

LLM predicts

```

Java

↓

is

↓

a

↓

programming

↓

language

```

One token at a time.

---

# What is Tokenization?

Tokenization is the process of converting text into tokens.

Example

```

Hello Spring AI

```

↓

```

Hello

Spring

AI

```

These tokens are converted into numbers before entering the neural network.

---

# What is Context Window?

Every LLM has a memory limit called the Context Window.

It defines how much information the model can remember during a conversation.

Example

GPT

```

Prompt

↓

Conversation History

↓

Documents

↓

Instructions

↓

Context Window

↓

Response

```

If the conversation exceeds the context window, older messages may no longer influence the response.

---

# What is Temperature?

Temperature controls randomness.

Low Temperature

```

0.1

```

Response

- More accurate
- More deterministic
- Better for coding

High Temperature

```

1.0

```

Response

- More creative
- More random
- Better for storytelling

---

# What is Top P?

Top P controls diversity.

Instead of considering every possible word, the model only considers the most probable words whose cumulative probability reaches P.

Example

```

Top P = 0.9

```

The model chooses from the top 90% probability mass.

---

# Temperature vs Top P

| Temperature | Top P |
|--------------|--------|
| Controls randomness | Controls candidate selection |
| High = Creative | High = More diverse |
| Low = Predictable | Low = More focused |

---

# What is a Prompt?

A Prompt is the instruction given to an AI model.

Example

```

Explain Spring Boot.

```

---

# Types of Prompts

## Zero Shot Prompt

```

Explain Dependency Injection.

```

---

## One Shot Prompt

```

Input

Java

Output

Programming Language

Now explain Spring Boot.

```

---

## Few Shot Prompt

Provide multiple examples before asking the model to perform the task.

This improves consistency and output quality.

---

# Prompt Lifecycle

```

User

↓

Prompt

↓

Tokenizer

↓

Tokens

↓

LLM

↓

Generated Tokens

↓

Final Response

```

---

# What is Prompt Engineering?

Prompt Engineering is the practice of designing prompts to get better responses from AI models.

A good prompt includes:

- Role
- Context
- Task
- Constraints
- Expected Output

---

# Example

Bad Prompt

```

Write code.

```

Good Prompt

```

You are an experienced Java Spring Boot developer.

Create a REST API for User Management using Java 21, Spring Boot 3.5, MySQL, JPA, and Global Exception Handling.

Return complete production-ready code.

```
